## 3. Uncovered Areas & Rationale

1. **`email_service.py` (14.0%):**  
   Real SMTP socket transmission is skipped in test runs because the test environment operates in `console` delivery mode to prevent reliance on external mail servers.
2. **`init_db.py` (0.0%):**  
   The database initialization script runs at server deployment time (DDL operations); tests utilize independent in-memory fixtures.
3. **`premium_code_service.py` & `ratings.py`:**  
   Secondary features developed on separate branches; core playback, subscription, catalog, authentication, and administration are prioritized for Sprint 1 & 2 evaluation.
